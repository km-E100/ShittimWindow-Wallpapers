# 什亭之窗 · 壁纸库

本仓库提供什亭之窗的记忆大厅资源目录和分包。应用本体请前往 [ShittimWindow](https://github.com/km-E100/ShittimWindow)。

当前资源版本：**2026.10.25-1**，共 **282 个记忆大厅、4903 个文件**。

## 推荐使用方法

安装本体后，在记忆大厅设置中点击 **下载完整壁纸库**。应用读取本仓库的 `catalog.json`，下载六个 ZIP 分包，逐包检查 SHA-256，全部安装成功后才切换资源库。之后可离线使用。

这些 ZIP 是同一资源库的六个部分，**不能把单个分包作为完整资源包导入**。

## 离线安装

1. 从 [资源 Release](https://github.com/km-E100/ShittimWindow-Wallpapers/releases/tag/2026.10.25-1) 下载全部六个 ZIP 和 `SHA256SUMS.txt`。
2. 核对 SHA-256 后，将六个 ZIP 全部解压到同一个空文件夹。最终该文件夹根目录必须包含 `manifest.json`。
3. Mac 可使用“导入自备资源包”选择该文件夹。Windows / Android 则把该文件夹中的全部内容压成一个 ZIP，再通过“导入自备资源包”导入。不要单独导入六个分包之一。

## 文件说明

- `catalog.json`：应用读取的版本、下载 URL、大小和 SHA-256。
- `wallpapers.json`：大厅列表。
- Releases：六个 ZIP 分包和校验文件；约 2.67 GB 下载量，解压后约 2.96 GB。
